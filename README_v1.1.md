# Version 1.1 — addendum to the replication package

Version 1.1 adds one script and changes no data. It accompanies the accepted version of the article,
whose Table 4 and Section IV-E (RQ1) were revised after peer review as follows:

1. **Table 4 is computed over the candidates that reach the verifier** (the `baseline` pool: candidates
   not self-rejected by the detector and not clamped to informational severity), so that the detector's
   own self-rejection is no longer counted as a verification decision. TP+FP+FN+TN therefore equals the
   *Baseline* column of Table 3 and the pool of Table 6. In version 1.0, `analysis/recompute.py:
   table_classification()` counted all detector candidates (self-rejected ones as FN/TN).
2. **F1 is averaged over all five runs**, with F1 = 0 for a run without a true positive (version 1.0
   averaged over the runs with at least one true positive).
3. The headline quantity is now called **alert-count reduction** ("Alert-cut" in Tables 3 and 10);
   the false-positive reduction proper (share of unlabelled pool findings withheld) is the *Removed FP*
   column of Table 6 and the complement of the FPR in Table 4.
4. A **random-removal reference** (hypergeometric probability that removing the same number of alerts
   uniformly at random would retain no more / no fewer true positives than the verifier did) is
   reported in RQ1.

`analysis_final_revision.py` (place it in `msfv-replication/analysis/` and run
`python3 final_revision.py pkg.pkl` after `load.py`) prints the revised Table 4, the false-positive
reduction proper for every detector–benchmark cell, and the random-removal comparison, and writes
`final_revision_numbers.json`. All other tables are unchanged and are regenerated by `emit_tex.py`
exactly as in version 1.0.
